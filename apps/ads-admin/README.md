# @dotlife/ads-admin · پنل تبلیغات نقطه

پنل مدیریت تبلیغ‌ها برای نیوتب نقطه، اپ نقطه و پاکت: یک جا برای ساختن، زمان‌بندی، پیش‌نمایش و انتشار تبلیغ‌های بومی. Vite، React 19، TypeScript سخت‌گیر، راست‌به‌چپ و با همان ظاهر نیوتب (توکن‌های `apps/newtab/src/styles.css`، کامپوننت `Tabs`، فونت یکان بخ).

```bash
pnpm --filter @dotlife/ads-admin dev     # http://localhost:5190
pnpm --filter @dotlife/ads-admin build
pnpm --filter @dotlife/ads-admin typecheck
```

## صفحه‌ها

- **جایگاه‌ها** (`#/slots`): ۱۵ جایگاه طرح، گروه‌بندی‌شده به اسلاید. هر کدام شماره، شکل، سقف، هدف‌گیری مجاز، مدل فروش و اینکه الان چه چیزی آن را پر کرده (زنده، زمان‌بندی‌شده، معرفی خود نقطه و پاکت، خالی). اگر در یک اسلاید بیش از سه جایگاه زنده باشد هشدار می‌دهد.
- **تبلیغ‌ها** (`#/ads`): فهرست با فیلتر جایگاه، وضعیت، محصول، آگهی‌دهنده و جستجو (در نشانی ذخیره می‌شود)، توقف و ادامه‌ی گروهی، کپی (به‌صورت پیش‌نویس)، حذف با تأیید.
- **ساخت و ویرایش** (`#/ads/new?slot=7`، `#/ads/edit/<id>`): فرم با فیلدهای ویژه‌ی هر جایگاه (`src/data/slotForm.ts`)، هدف‌گیری فقط با بُعدهایی که جایگاه اجازه می‌دهد، زمان‌بندی، وزن، مدل فروش، قیمت و سقف روزانه. اعتبارسنجی با zod و پیام فارسی؛ پیش‌نمایش زنده در شکل خود جایگاه با برچسب «معرفی‌شده».
- **انتشار** (`#/publish`): ساخت بسته‌ی تازه (نسخه + ۱)، نمایش JSON با جای امضا، خروجی، درون‌ریزی با ادغام یا جایگزینی.
- **داشبورد** (`#/dashboard`، نسخه‌ی اول): نمایش، کلیک و CTR هر جایگاه و هر تبلیغ، با سوییچ محصول و بازه.

## ساختار

- `src/data/store.ts`: رابط `AdsStore` و پیاده‌سازی `LocalAdsStore` روی `localStorage`. بقیه‌ی پنل فقط از این رابط می‌خواند؛ قرارداد سرور آینده در `docs/ads-api.md`.
- `src/data/events.ts`: رابط `EventsStore` برای شمارنده‌های نمایش و کلیک (به‌صورت جمع روزانه، بدون شناسه‌ی شخصی)، `LocalEventsStore` و داده‌ی آزمایشی. محصول (`newtab`، `noghte`، `paket`) جزو هر ردیف است، پس محصول تازه فقط یک مقدار تازه است.
- `src/data/logic.ts`: قانون‌های خالص (بدون React): فاز تبلیغ در امروز، پرشدگی جایگاه، فیلتر، کارهای گروهی، ساخت بسته، JSON استاندارد برای امضا، درون‌ریزی.
- `src/data/validate.ts`: شِمای مشترک `@dotlife/ads` به‌علاوه‌ی قانون‌های هر جایگاه، با پیام فارسی.
- `src/ui/AdPreview.tsx`: پیش‌نمایش هر ۱۵ جایگاه.

## هنوز ساختگی است

- **ذخیره:** `localStorage` مرورگر (`LocalAdsStore`). تا سرور نیست تبلیغ‌ها فقط در همین مرورگرند. اولین بار که چیزی ذخیره نشده، نمونه‌های `SAMPLE_ADS` به‌عنوان نقطه‌ی شروع آمده‌اند.
- **امضا:** بسته بدون امضا ساخته می‌شود و صفحه‌ی انتشار جای خالی `<ed25519 · base64 · امضای سرور>` را نشان می‌دهد؛ SHA-256 متن امضاشونده فقط برای مقایسه است.
- **رویدادها:** شمارنده‌ها را کلاینت‌ها نمی‌فرستند؛ فقط دکمه‌ی «افزودن داده‌ی آزمایشی» آن‌ها را پر می‌کند. نیوتب بعداً به `POST /v1/ads/events` می‌فرستد.
- **داشبورد یکپارچه** (اپ نقطه، افزونه، پاکت و محصول‌های دیگر کنار هم): بعدی است.
