# نقطه برای کروم · افزونه‌ی نیوتب نقطه و پاکت

نیوتب کروم که نقطه (کارها، یادداشت‌ها، برنامه‌ها) و پاکت (پول) را روی هر تب تازه می‌آورد، با سرچ گوگل در مرکز.

- طرح و ماک‌آپ تعاملی: `design/prototypes/newtab.html`
- کد افزونه: `apps/newtab` (نسخه‌ی ۰.۱: صفحه‌ی اول و همگام‌سازی با نقطه؛ راهنمای ساخت و نصب در `apps/newtab/README.md`)
- `packages/`: کپی پکیج‌های مشترک dotlife (همگام‌سازی، کارها، تقویم، مناسبت‌ها، اوقات شرعی)؛ `packages/VENDORED.md`

این مخزن از مونوریپوی [dotlife](https://github.com/mostafauxd-cmyk/dotlife) جدا شده است.

- تبلیغ‌ها: نیوتب جایگاه‌های بومی را از روی مدل `packages/ads` می‌کشد. پنل مدیریت تبلیغ‌ها و مدل اصلی در مخزن جدای **nx-ads** هستند (قرارداد API و امنیت هم همان‌جا). `packages/ads` این‌جا کپی همان است.
