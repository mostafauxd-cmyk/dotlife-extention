# @dotlife/tasks

منطق خالص کارها (PLAN §15): مدل، اعتبارسنجی، بازه‌ی زمانی، تکرار تقویم‌آگاه، کوئری‌ها و ویرایش. بدون UI، بدون دیتابیس، بدون `Date` (جز `localNow`).

## مدل

- **تاریخ‌ها میلادی ISO** ذخیره می‌شوند (`"2026-10-05"`) و فقط در نمایش به خورشیدی/قمری/شاهنشاهی تبدیل می‌شوند. ساعت‌ها wall-clock در `timeZone` خودِ کار.
- `TaskSchedule`: `none` (بدون تاریخ) · `due` (مهلت) · `range` (شروع و پایان؛ می‌تواند چندروزه باشد). نقطه‌ی بدون ساعت = تمام‌روز.
- `Recurrence`: روزانه / هفتگی (`byWeekday`، شنبه=۰) / ماهانه (`dayOfMonth` یا `nthWeekday`) / سالانه، با `interval`، پایان `never` / `until` / `count`، و **`calendar`**: «اول هر ماه» در خورشیدی ≠ میلادی.
- `OccurrenceOverride`: استثنای یک نمونه (انجام‌شده، حذف‌شده، جابه‌جاشده، عنوان متفاوت).
- `Task`: id (UUID v7)، لیست، عنوان، وضعیت، اولویت، schedule (برای تکراری = اولین نمونه)، recurrence، overrides، یادآوری‌ها، `order` (fractional index)، زمان‌ها و soft delete.

## قواعد اعتبارسنجی

`end ≥ start` · شروع و پایان یا هر دو ساعت‌دار یا هر دو تمام‌روز · کار تکراری بدون مهلت/بازه نامعتبر · `until` قبل از اولین نمونه نامعتبر · تاریخ باید وجود داشته باشد. خطاها `TaskValidationError` با `code` و پیام فارسی.

## تکرار (`expandOccurrences(task, {from, to})`)

- **تنبل:** فقط نمونه‌های داخل پنجره ساخته می‌شوند؛ سری «بی‌پایان» هرگز کامل ساخته نمی‌شود (سقف `MAX_OCCURRENCES`).
- **تقویم‌آگاه:** ماهانه‌ی خورشیدی روی ۳۱ شهریور → ۳۰ مهر، …، ۲۹ اسفند؛ سالانه‌ی ۳۰ اسفند فقط در سال‌های کبیسه، وگرنه ۲۹ اسفند. قمری با تقویم حسابیِ `calendar-core` (نه قمری رسمی).
- نمونه‌ی بازه‌دار طول خودش را حفظ می‌کند و در **همه‌ی** روزهایی که می‌پوشاند دیده می‌شود.

## کوئری‌ها (همه با `now: { date, time }` محلی — `localNow(timeZone)`)

| تابع                            | معنی                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| `tasksOnDay(tasks, day)`        | بازه‌شان این روز را **می‌پوشاند** (نه فقط شروعشان)؛ مرتب بر اساس شروع، تمام‌روزها اول |
| `tasksBetween(tasks, from, to)` | برای جدول ماه                                                                         |
| `overdue(tasks, now)`           | `todo` و مهلت (due یا پایان بازه) گذشته؛ مهلت تمام‌روز آخر روز منقضی می‌شود           |
| `inProgress(tasks, now)`        | بازه‌ای که الان بینش هستیم                                                            |
| `upcoming(tasks, now, days)`    | شروع بعد از الان تا n روز                                                             |
| `unscheduled(tasks)`            | inbox                                                                                 |
| `rightNow(tasks, now)`          | بلوک «همین الان» بخش کارها: در جریان + عقب‌افتاده                                     |

## ویرایش کار تکراری (سه حالت)

| حالت            | تابع                                                                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «فقط این یکی»   | `completeOccurrence` · `cancelOccurrence` · `moveOccurrence` · `overrideOccurrence`                                                                           |
| «این و بعدی‌ها» | `splitSeries(task, fromDate, changes, newId, now)` → سری اصلی تا روز قبل، سری جدید از همان روز؛ overrideها به سمت درست می‌روند؛ `count` باقی‌مانده حفظ می‌شود |
| «همه»           | ویرایش معمولی خودِ `Task`                                                                                                                                     |

## کمکی‌ها

- `localNow(timeZone, instant?)` — تنها جایی که به لحظه‌ی واقعی نگاه می‌شود؛ مرز روز با منطقه‌ی زمانی خودِ کار (DST و سفر).
- `orderBetween(a?, b?)` — کلید مرتب‌سازی دستی که بین دو کلید می‌نشیند؛ مقایسه‌ی لغوی ساده، مناسب `ORDER BY` در SQLite.
- `uuidv7()` — شناسه‌ی زمان‌مرتب، ساخت آفلاین.
- `reminderTimes(occurrence, reminders)` — زمان‌های یادآوری محلی (برای local notification).

## تست‌ها

اعتبارسنجی · تاریخ‌ها و `localNow` در سه منطقه‌ی زمانی (تهران، لندن با/بی DST، لس‌آنجلس) · تکرار روزانه/هفتگی/ماهانه (خورشیدی با clamp، میلادی، nth weekday)/سالانه (۳۰ اسفند)/قمری · until و count · overrideها · سقف نمونه‌ها · کوئری‌ها با بازه‌ی چندروزه و زمان‌دار · سه حالت ویرایش · fractional index با ۵۰۰ درج تصادفی · UUID v7 · یادآوری‌ها.
