# @dotlife/prayer-times

محاسبه‌ی اوقات شرعی و قبله — خالص TypeScript، بدون وابستگی به زمان سیستم یا شبکه.

## روش‌ها (`PrayerCalcMethod`)

هر روش فقط یک مجموعه پارامتر است (زاویه‌ی صبح، مغرب، عشاء، تعریف نیمه‌شب)؛ افزودن روش جدید = یک سطر داده.

| روش                                  | صبح                                | مغرب   | عشاء                 | نیمه‌شب          |
| ------------------------------------ | ---------------------------------- | ------ | -------------------- | ---------------- |
| `tehran` (پیش‌فرض)                   | ۱۸°                                | ۴٫۳°   | ۱۴°                  | غروب تا اذان صبح |
| `jafari`                             | ۱۶°                                | ۴°     | ۱۴°                  | غروب تا اذان صبح |
| `mwl` · `isna` · `egypt` · `karachi` | ۱۸ · ۱۵ · ۱۹٫۵ · ۱۸                | = غروب | ۱۷ · ۱۵ · ۱۷٫۵ · ۱۸  | غروب تا طلوع     |
| `makkah`                             | ۱۸٫۵°                              | = غروب | ۹۰ دقیقه بعد از مغرب | غروب تا طلوع     |
| `custom`                             | هر چه کاربر بدهد؛ بقیه از `tehran` |        |                      |                  |

**درباره‌ی `tehran`:** مؤسسه ژئوفیزیک رسماً ۱۷٫۷° / ۴٫۵° اعلام می‌کند، ولی در مقایسه با جدول رسمی time.ir (۵ شهر، ۱۲ مهر ۱۴۰۵) این مقادیر ۱ تا ۲ دقیقه دیر می‌دهند و ۱۸° / ۴٫۳° همه‌ی اذان صبح‌ها و مغرب‌ها را دقیقاً بازتولید می‌کند. این کالیبراسیون تجربی است و باید با جدول یک سال کامل دوباره بررسی شود (کار باقی‌مانده).

تنظیمات دیگر (`PrayerSettings`): روش عصر (`standard`/`hanafi`)، قاعده‌ی عرض‌های بالا، فاصله‌ی امساک، و تنظیم دستی ± دقیقه برای هر وقت.

## الگوریتم

همان الگوریتم PrayTimes.org (حمید ضرابی‌زاده): موقعیت خورشید با تقریب NOAA، یک دور تصحیح، و قواعد عرض‌های بالا (`night-middle`، `one-seventh`، `angle-based`، `none`). وقتی خورشید به زاویه نمی‌رسد و قاعده‌ای فعال نیست، مقدار `null` است.

ارتفاع از سطح دریا **به‌صورت پیش‌فرض نادیده گرفته می‌شود**؛ جدول‌های رسمی ایران افق دریا را مبنا می‌گیرند (با ارتفاع ۱۱۹۰ متر تهران، طلوع ۶ دقیقه زودتر می‌شد و با time.ir نمی‌خواند).

## API

```ts
import {
  computePrayerTimes,
  nextPrayer,
  formatMinutes,
  qiblaBearing,
  IRAN_UTC_OFFSET_HOURS,
} from "@dotlife/prayer-times";

const t = computePrayerTimes({
  date: { year: 2026, month: 10, day: 4 }, // میلادی، در منطقه‌ی زمانی محل
  location: { latitude: 35.6892, longitude: 51.389 }, // تهران
  utcOffsetHours: IRAN_UTC_OFFSET_HOURS, // +3.5، ایران DST ندارد
  settings: { method: "tehran" }, // اختیاری
});
// t = { fajr: 277, sunrise: 362, dhuhr: 713, sunset: 1064, maghrib: 1081, midnight: 1391, … } — دقیقه از نیمه‌شب
formatMinutes(t.fajr!); // "04:37"
nextPrayer(t, 11 * 60 + 30); // { name: "dhuhr", minutes: 713, remainingMinutes: 23 }
qiblaBearing({ latitude: 35.6892, longitude: 51.389 }); // 218.4° از شمال، ساعت‌گرد
```

## تست‌ها

- **time.ir، ۱۲ مهر ۱۴۰۵:** تهران، مشهد، تبریز، بندرعباس، زاهدان — هر شش وقتِ منتشرشده در بازه‌ی ۱ دقیقه؛ ۲۸ از ۳۰ مقدار دقیقاً برابر
- ترتیب اوقات در همه‌ی روش‌ها، تفاوت جعفری/تهران، عشاء ۹۰ دقیقه‌ای مکه، عصر حنفی، تنظیم دستی، امساک، نیمه‌شب جعفری/استاندارد
- عرض‌های بالا (اسلو در انقلاب تابستانی): بدون قاعده `null`، با قاعده همیشه مقدار دارد
- قبله: تهران ≈ ۲۱۸°، جاکارتا ≈ ۲۹۵°، فاصله‌ی تهران تا کعبه ≈ ۱۹۵۰ km

## کار باقی‌مانده

- اعتبارسنجی `tehran` روی یک سال کامل (time.ir فقط امروز را نشان می‌دهد؛ منبع: جدول سالانه‌ی مؤسسه ژئوفیزیک)
- پایگاه شهرهای ایران با مختصات (برای انتخاب شهر بدون GPS) — در قدم اپ
