# @dotlife/calendar-core

موتور تقویم — تبدیل بین چهار گاه‌شمار، خالص TypeScript، بدون وابستگی.

| گاه‌شمار        | `CalendarSystem` | الگوریتم                                                                                                                                 |
| --------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| خورشیدی (جلالی) | `solar-hijri`    | Borkowski (جدول شکست‌های ۳۳ساله) — مطابق تقویم رسمی ایران، سال‌های ۱ تا ۳۱۷۷                                                             |
| شاهنشاهی        | `shahanshahi`    | همان خورشیدی، سال + ۱۱۸۰                                                                                                                 |
| میلادی          | `gregorian`      | Fliegel–Van Flandern (پرولپتیک)                                                                                                          |
| قمری            | `hijri`          | **جدولی/حسابی** (چرخه‌ی ۳۰ساله). تقویم رسمی ایران رؤیتی است و ممکن است ±۱ روز فرق کند؛ جدول اصلاح در قدم «داده‌ی مناسبت‌ها» اضافه می‌شود |

همه‌ی تبدیل‌ها از طریق **Julian Day Number** انجام می‌شود؛ هیچ تقویمی مستقیم به دیگری تبدیل نمی‌شود.

## API

```ts
import { convert, today, weekday, daysInMonth, addDays, monthName } from "@dotlife/calendar-core";

const t = today("solar-hijri"); // { calendar: "solar-hijri", year: 1405, month: 7, day: 12 }
convert(t, "hijri"); // { calendar: "hijri", year: 1448, month: 4, day: 21 }
weekday(t); // 1  (شنبه = ۰ … جمعه = ۶)
daysInMonth("solar-hijri", 1403, 12); // 30 (سال کبیسه)
addDays(t, 19); // ۱ آبان ۱۴۰۵
monthName(t); // "مهر"
```

سایر توابع: `toJdn`, `fromJdn`, `isLeapYear`, `isValid`, `validate`, `daysBetween`, `compare`, `isSameDay`, `weekdayOfJdn`, ثابت‌های `MONTH_NAMES_FA` و `WEEKDAY_NAMES_FA`.

## تست‌ها

- تاریخ‌های مرجع: نوروز ۱۴۰۰ تا ۱۴۰۵، سال کبیسه‌ی ۱۴۰۳، ۱ فروردین ۱، ۱ فروردین ۱۵۰۰، مبدأ هجری، …
- **هر روزِ** ۱۹۰۰ تا ۲۱۰۰ در هر چهار تقویم: رفت‌وبرگشت از JDN، اعتبار تاریخ، و پیوستگی روزهای متوالی
- **داده‌ی مرجع time.ir** (`test/fixtures/time-ir.txt`): ۲۱۹۲ روز در ۷۲ ماه بین دی ۱۴۰۱ و تیر ۱۴۰۸ که از تقویم رسمی time.ir برداشته شده. خورشیدی ↔ میلادی باید روی **تک‌تک** روزها دقیقاً یکی باشد؛ قمری حسابی باید در بازه‌ی ±۱ روزِ قمری رسمی (رؤیتی) بماند — در این نمونه ۵۵٪ روزها دقیقاً برابر، ۳۱٪ یک روز جلوتر و ۱۴٪ یک روز عقب‌تر است
- طول ماه‌ها، اعتبارسنجی، حساب روزها

## نکته‌ی پیاده‌سازی

فرمول‌های Borkowski با **تقسیم به سمت صفر** (`Math.trunc`) طراحی شده‌اند، نه کف (`Math.floor`). استفاده از کف، نتیجه را یک سال جابه‌جا می‌کند. `math.ts` هر دو را جدا دارد: `tdiv/tmod` برای خورشیدی و میلادی، `div/mod` برای قمری و روز هفته.
